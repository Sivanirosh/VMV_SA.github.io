# VMV Udhavikkaram — Public Website

Public website for **VMV Udhavikkaram (Helping Hand)** and **Sulakshana Free Education Centre** in Pungudutivu, Sri Lanka.

The site presents the organisation’s real origin, education work, student welfare activities, community service and future planning. Donation and volunteer features are intentionally disabled for now until VMV confirms official public channels.

## Stack

- **Framework:** Astro 4 + Tailwind CSS 3
- **Content:** Astro Content Collections (Markdown)
- **Hosting:** GitHub Pages during the prototype/publication-prep phase

## Development

```bash
npm install
npm run dev
```

## Deployment

Deployed automatically via GitHub Actions on push to `main`. See `.github/workflows/deploy.yml`.
